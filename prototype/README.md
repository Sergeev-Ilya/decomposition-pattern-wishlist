# Wishlist — кликабельный прототип

React + Vite + TypeScript + Tailwind CSS v4. Все экраны из `docs/pages-spec.md` реализованы на фиктивных данных, без API и backend.

## Запуск

```bash
cd prototype
npm install
npm run dev
```

Откройте URL из вывода Vite, обычно `http://localhost:5173`. Не используйте Live Preview и не открывайте `index.html` напрямую: стили Tailwind собираются через Vite.

Проверка типов и сборка: `npm run build`.

## Просмотр

- Главная: `/`.
- Вход владельца: `/login`, email `maria@example.com`, пароль `Wishlist2026!`.
- Кабинет после входа: `/wishlists`.
- Пример списка: `/wishlists/birthday` после входа.
- Гостевой список без входа: `/s/birthday-demo`.
- После бронирования скопируйте личную ссылку и откройте ее для отмены.
- `/r/reserved-demo-token` — заранее забронированный пример, только для проверки прототипа.

Проверка: войти, создать/изменить список и подарок, поделиться ссылкой; выйти, открыть общую ссылку, забронировать подарок, сохранить личную ссылку и отменить бронь. Собственный список в авторизованной сессии не показывает доступность подарков. Для проверки регистрацией создайте фиктивный аккаунт с паролем от 12 символов; его списки сначала пусты.

## Ограничения прототипа

- Все fixtures, типы и mock-операции находятся в `src/data/mock.ts`.
- Данные и условная сессия сохраняются в `sessionStorage` этой вкладки. После закрытия вкладки они могут исчезнуть. Разные вкладки/браузеры не синхронизируются; это не сервис с общей базой данных.
- Для гостевого просмотра измененного списка скопируйте ссылку, выйдите из аккаунта и откройте ее в той же вкладке. В отдельной вкладке гарантирован только исходный пример `/s/birthday-demo`.
- Авторизация, права, бронирование и конфликты имитируются в браузере. Серверной защиты, настоящих HttpOnly cookie/JWT, транзакций БД и гарантий конкурентности здесь нет.
- Для демонстрации секреты броней и идентификатор сессии находятся в mock-состоянии `sessionStorage`, не в `localStorage`. Они не являются защищенными серверными секретами. Не вводите реальные пароли или личные данные.
- Пароль демонстрационного пользователя задан fixture. Для регистраций хранится демонстрационный SHA-256 digest, который не заменяет стойкий серверный хеш пароля.
- После отмены ссылка показывает отмененную бронь и не управляет последующей бронью этого подарка. Замена общей ссылки не меняет личные ссылки отмены.
- Копирование работает на localhost/HTTPS; если буфер недоступен, показывается поле ручного копирования.

Сброс данных: откройте DevTools → Application → Session storage и удалите ключ `wishlist-prototype-v1`, затем обновите страницу. Либо выполните в консоли только для этого прототипа:

```js
sessionStorage.removeItem('wishlist-prototype-v1');
location.reload();
```
