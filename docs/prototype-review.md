# Wishlist — проверка прототипа

Дата: 2026-10-28. Статус: **прототип утвержден пользователем**: «Утверждаю прототип». Фаза проекта — `prototype_review`; следующий шаг — согласование параметров развертывания и инфраструктуры.

## Просмотр

- Локальный Vite-сервер: http://127.0.0.1:5173/.
- Общий пример без входа: http://127.0.0.1:5173/s/birthday-demo.
- Вход владельца: `maria@example.com` / `Wishlist2026!` — только фиктивный аккаунт прототипа.
- Запуск, сброс и ограничения: [prototype/README.md](../prototype/README.md).

## Проверено

- `npm run build` в `prototype/`: TypeScript и Vite завершились с кодом 0; CSS Tailwind присутствует в сборке.
- В браузере визуально подтверждены оформление, иллюстрации, типографика и адаптивная сетка.
- Вход фиктивного владельца, создание списка и добавление подарка с обязательными названием и ценой, без ссылки; сумма `1250,50` показана как `1 250,50 ₽`.
- Общая ссылка открывается; авторизованный владелец не видит статусы и действия бронирования своего списка.
- После выхода гость видит доступность, бронирует подарок через подтверждение и получает отдельную личную ссылку.
- Личная ссылка показывает бронь; подтвержденная отмена переводит ее в отмененное состояние.
- Регистрация нового фиктивного пользователя приводит в пустой кабинет.
- Недействительные общая и личная ссылки показывают состояния недоступности; неизвестный маршрут показывает страницу «Не найдено».
- На ширинах 360 и 390 px проверены адаптивные экраны, на 1440 px — настольные; горизонтального переполнения в проверенных состояниях нет.
- На проверенных переходах ошибок и предупреждений консоли не обнаружено. Временные данные ручной проверки сброшены, для просмотра восстановлены исходные примеры.

## Границы результата

Это кликабельный прототип с данными вкладки браузера, без backend, API и общей БД. Бронирования, права и сессии имитируются; реальная конкурентность и серверная защита здесь не проверяются. Данные между вкладками и устройствами не синхронизируются. Полные ограничения описаны в README.

Эта проверка не является e2e готового сервиса: `tests.backend` и `tests.frontend` остаются `pending`, адрес развернутого продукта не задан. Прототип утвержден; после согласования параметров развертывания и инфраструктуры можно переходить к архитектуре.
