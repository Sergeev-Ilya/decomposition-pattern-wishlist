# Wishlist — параметры первого запуска

Статус: **локальный запуск утвержден пользователем 2026-10-28**: «Подтверждаю локальный запуск». Продукт еще не развернут; `baseUrl` не задан.

## Принятый вариант

| Параметр | Решение |
|----------|-------------|
| Окружение | Локальный запуск через Docker Compose |
| Состав | Интерфейс, API gateway, сервисы приложения и PostgreSQL согласно будущей архитектуре |
| Адрес | Предварительно `http://localhost:8880`; фактический адрес фиксируется только после запуска и проверки API |
| Доступ к серверу | Для локального запуска не требуется |
| Дополнительная инфраструктура | Без брокера сообщений и S3, в соответствии с выбранным стеком |
| CI | Без CI на первом этапе |
| Домен | Не требуется для локального запуска |

Локальный запуск позволит проверить полные сценарии с настоящей БД. Ссылки localhost доступны только на компьютере с запущенным приложением; для обмена с другими людьми через интернет потребуется удаленное окружение.

## Если выбран удаленный сервер

Нужно получить одним ответом: адрес сервера, пользователя SSH, путь приложения на сервере, имя файла ключа в `.ssh/`, домен при наличии и предпочтение по CI. Содержимое закрытого ключа в чате не требуется. Ресурсы и стоимость сервера не определяются без выбора пользователя.

Принятые параметры записаны в `.project/deploy.json`, `approvals.batchApprovals = true`. Следующий этап — проектирование архитектуры. Раздел об удаленном сервере оставлен для возможного будущего переноса; сейчас удаленный запуск не выполняется.
